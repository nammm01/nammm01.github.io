PushBox (Sokoban)
"Puzzle game"







PushBox adalah adaptasi dari game klasik Sokoban dengan gameplay sederhana: pemain menggerakkan karakter untuk mendorong kotak ke posisi tujuan. Walau sederhana, game ini menghadirkan tantangan strategis yang melatih logika dan perencanaan langkah.

Key Features

  • Gameplay sederhana namun menantang: mendorong kotak hingga ke posisi tujuan tanpa jalan mundur, hanya opsi reset
  • Nostalgia klasik: berdasarkan game populer era 1980-an (MS-DOS, Nintendo)
  • Multi-platform ready: dapat diakses melalui smartphone, tablet, maupun komputer
  • Cognitive training: melatih kecerdasan dan kemampuan memilih jalur

Development

  • Bahasa pemrograman: Java
  • IDE: Visual Studio Code dengan Extension Pack for Java
  • Library: javax.swing (GUI & event), java.awt (komponen UI), java.io (file I/O), java.util (struktur data)
  • Struktur kode:
    • pushthebox → kelas utama (Main.java)
    • player → kelas aktor (player, point, wall, crate) serta resource
