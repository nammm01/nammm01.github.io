PushBox (Sokoban)

Source code and app






PushBox is an adaptation of the classic Sokoban game with simple yet engaging gameplay. Players must move the character and push boxes to their designated destinations. Although the mechanics are straightforward, the game provides challenging puzzles that help develop logical thinking and planning skills.

Development

  • Programming Language: Java
  • IDE: VSCode
  • Libraries:
    • javax.swing (GUI and event handling)
    • java.awt (UI components)
    • java.io (file I/O)
    • java.util (data structures and utilities)
  • Code Structure:
    • pushthebox → Main class (Main.java)
    • player → Player-related classes (Player, Point, Wall, Crate) and resources
