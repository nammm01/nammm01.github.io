Parucare





Parucare is a website prediction lung health that build to help user/people to initial check online lung condition. user can input data that use from website interface, then the system will process that data and give the result prediction that can use as initial reference. This website developed with focus at user convenience, accessibility, and delivery of health information.

Key Features

  • Lung health prediction through website
  • Form input data which is easy to use
  • Show Prediction result
  • Responsive design for desktop and mobile
  • Data validate for increase input accuracy
  • Simple interface and easy to use

Development

  • Frontend: HTML, CSS, JavaScript
  • Frameworks & Libraries: Bootstrap, jQuery
  • Backend: PHP (Laravel)
  • Database: MySQL
